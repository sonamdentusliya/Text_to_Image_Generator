# Text to Image Generator 🎨
# 📌 Project Description

Text to Image Generator is a simple web application that generates an image based on a user’s text prompt. It uses the Unsplash API to fetch relevant images and display them dynamically on the webpage.

Users can enter any keyword (e.g., "cat", "nature", "space") and the application will fetch and display a related image.

# 🚀 Features

Generate images from text prompts

Fetch images using Unsplash API

Loading animation while fetching data

Error handling for empty input or failed requests

Clean and responsive UI

Modern dark theme design

# 🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES6)

Unsplash API

# ⚙️ How It Works

User enters a text prompt.

JavaScript captures the input.

A request is sent to the Unsplash API.

The API returns an image based on the search query.

The image is displayed dynamically on the page.

# 🔑 API Configuration

This project uses the Unsplash API.

To use your own API key:

Create an account at https://unsplash.com/developers

Generate a new Access Key.

Replace the Client-ID in script.js with your own key:
'Authorization': 'Client-ID YOUR_ACCESS_KEY'
